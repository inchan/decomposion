# Planning Eval v1 — review questions

1. **Explicitness:** may a critical obligation count as covered when it is only implied, or must a human reviewer be able to point to explicit candidate text?
2. **Granularity:** should Step 2 encode `must_separate` / `may_group` constraints, or keep granularity human-adjudicated for v1?
3. **Critical failures:** should selected security/data-loss `critical` misses become hard failures after baseline distributions are observed?
4. **Novel findings:** should evidence-backed novel findings remain neutral until adjudicated, or receive provisional positive credit?
5. **Golden authorship:** who should independently review the first three reference cases so the same reasoning that builds Decomposion does not define all of its own answers?

These questions are intentionally unresolved at the Step 1 checkpoint.
